# Misión

## Qué construimos
Un formulario web al que se ingresa escaneando un código QR, para registrar la asistencia de trabajadores y visitantes de TranSuperior S.A.S. Cada registro se guarda en base de datos y llega por correo a la trabajadora encargada.

## Para quién
- **Trabajadores y visitantes:** escanean el QR desde el celular y llenan el formulario. No tienen cuenta ni login.
- **Trabajadora encargada:** recibe un correo por cada registro.

## Criterios de éxito
- Una persona completa el registro en menos de 1 minuto desde el celular.
- Ningún registro se pierde, aunque falle el envío del correo.
- El correo llega a la encargada con todos los datos del registro.

## Principios
- **Simple:** pocas pantallas, poco texto, un solo botón principal.
- **Confiable:** primero se guarda, después se notifica.
- **Privado:** solo se piden los datos necesarios y con autorización expresa.

## Fuera de alcance (por ahora)
Login, panel administrativo, reportes, exportaciones y segundo escaneo para registrar la salida real.
